Omen Threat Meter — это аддон для World of Warcraft 3.3.5, предназначенный для отслеживания угрозы (агро) во время боя. Он показывает, сколько агро создаёт каждый участник группы или рейда по отношению к текущей цели, помогая игрокам контролировать уровень угрозы и избегать случайного привлечения внимания противников.

Omen особенно полезен танкам и дамагерам: первые могут следить, удерживают ли они агро, а вторые — вовремя снижать урон или использовать способности для сброса угрозы. Аддон отображает данные в виде удобных полос с процентами и цветовой индикацией, что позволяет моментально оценить ситуацию.

Благодаря совместимости с системами угрозы Blizzard и другими модами (например, KTM), Omen стал стандартом для рейдовых групп, помогая поддерживать порядок в бою и избегать хаоса при агрессивных сражениях.
